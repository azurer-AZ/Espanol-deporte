2️⃣ 动词原形 · 对话中出现或相关
原形中文说明
jugar打（球）后接 a + 运动，常缩合为 al（如 jugar al tenis）。
saber会（技能）后接动词原形，表能力（sé jugar）。
enseñar教常接 a + 原形（enseñar a jugar）。
correr跑可接距离（correr largas distancias）。
gustar使喜欢特殊用法：主语是事物，间接宾语是人。
interesar使感兴趣用法同 gustar。
invitar邀请常接 a + 原形（invitar a jugar）。
estar在 / 状态用于位置或临时状态。
hacer做（锻炼）hacer ejercicio（固定搭配）。
tener有表拥有，如 tener un buen cuerpo。
3️⃣ 动词变位 · 现在时 · 简单过去 · 过去未完成
原形 中文 现在时 (yo) 简单过去 (yo) 过去未完成 (yo) 时态使用提示
jugar 打 juego jugué jugaba 现在表习惯；简单过去表一次已结束；未完成表过去背景
saber 会 sé supe sabía 现在表当前能力；简单过去表“突然知道”；未完成表过去知道状态
enseñar 教 enseño enseñé enseñaba 简单过去表那一次教；未完成表过去经常教
correr 跑 corro corrí corría 简单过去表跑过一次；未完成表过去习惯跑
gustar 使喜欢 gusta / gustan gustó / gustaron gustaba / gustaban 第三人称；现在表当前喜好；未完成表过去曾经喜欢
interesar 使感兴趣 interesa / interesan interesó / interesaron interesaba / interesaban 用法同 gustar
invitar 邀请 invito invité invitaba 简单过去表那一次邀请；未完成表过去常邀请
estar 在 estoy estuve estaba 简单过去表过去某一时间点状态；未完成表持续背景
hacer 做 hago hice hacía 现在表习惯；简单过去表一次；未完成表过去习惯
tener 有 tengo tuve tenía 现在表拥有；未完成表过去拥有状态
📌 时态小结： 现在时用于事实、习惯；简单过去用于一次性完成动作；过去未完成用于背景、持续状态或过去习惯。

5️⃣ 语法要点 · 结构 + 例句
🔹 gustar / interesar 的用法
• 主语是“事物”，间接宾语是“人”。
• 结构：A + 人 + le/les + gusta(n) + 事物
• 单数用 gusta，复数用 gustan。
• 例：Me gusta el tenis. （我喜欢网球。）
• 否定：No me interesan esos deportes.
🔹 saber vs. poder
• saber + 原形 = 会（掌握技能）→ Sé jugar.
• poder + 原形 = 能够 / 允许 → Puedo jugar hoy.
🔹 简单过去 vs. 过去未完成
• 简单过去：一次性、已完成的动作（enseñaron, invitaron）。
• 过去未完成：背景、持续状态、过去习惯（estaba）。
• 常搭配：未完成提供背景，简单过去叙述事件。
🔹 介词 a 与缩合 al
• jugar a + 运动，若运动带 el，缩合为 al（jugar al tenis）。
• 拉美可省略为 jugar tenis。
🔹 固定表达 darse bien / mal
• Se me da bien... = 我擅长……
• 否定：No se me da muy bien el deporte. = 我运动一般般。
🔹 表达“最不喜欢”
• 用 el/la que menos + 动词 或 lo que menos。
• 例：El deporte que menos me gusta es correr largas distancias.
🔹 目的状语：para + 动词原形
• 表示“为了……”→ para tener un buen cuerpo
🔹 时间状语：cuando + 陈述式
• 表过去背景时常用过去未完成：Cuando estaba en la primaria...
